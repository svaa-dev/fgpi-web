---
name: frontend
description: Skills para el desarrollo general del frontend del proyecto
---

- Estructurar con HTML5 semántico. Evita el uso innecesario de `div` y `span`. Busca la etiqueta semántica que mejor represente el contenido.

- Estilizar con Tailwind CSS v4.3.

- TypeScript estricto con comentarios explicativos.

- Seleccionar imagenes e iconos de las carpetas `src/images` y `src/icons`

- Extrae de `src/styles/global.css` los tokens de diseño.

- Crea las animaciones con @keyframes en `src/styles/global.css`.
